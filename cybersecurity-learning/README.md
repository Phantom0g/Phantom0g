# Cybersecurity Learning
**A beginner learning workspace by Oluwaseun Adeosun**

I am building my understanding of security fundamentals, HTTP and APIs. This project contains introductory notes and a small lab designed for local practice.

These materials are starter learning resources prepared with assistance. Their publication does not mean I have completed the exercises or earned a security certification. I will document completed work in the learning log.

| Resource | Purpose | Current status |
| --- | --- | --- |
| [Security fundamentals](security-fundamentals.md) | Distinguish authentication, authorization and basic account protection | Starter guide |
| [Local HTTP/API lab](local-http-api-lab/README.md) | Run a local JSON API and inspect requests, status codes and headers | Runnable exercise |
| [Learning log](learning-log.md) | Record dates, observations and next steps | No completed entries yet |

## Learning path
1. Read the fundamentals and explain authentication versus authorization in my own words.
2. Run the local lab and observe successful and missing-resource responses.
3. Record the output, what I understood and one follow-up question.
4. Add a dated write-up when I complete an authorized training exercise.

## Scope
The included lab sends two requests to a server it starts on **127.0.0.1** on my own machine, then shuts it down. It has no messaging, scraping, account automation or third-party scanning feature.
