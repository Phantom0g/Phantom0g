# Content Strategy Toolkit
**Reusable planning tools by Oluwaseun Adeosun**

A practical starter pack for planning content, reviewing results and preparing event partnership proposals.

| Resource | Use |
| --- | --- |
| [Two-week content calendar](two-week-content-calendar.md) | A worked planning example for a talent competition |
| [Weekly performance report](weekly-performance-report.md) | A fill-in template with clear metric definitions |
| [Partnership proposal framework](partnership-proposal-framework.md) | A structured template for an event venue pitch |

## Start here
1. Choose one campaign objective and audience.
2. Adapt the example calendar to actual dates, approved assets and platform needs.
3. Track results using the weekly report.
4. Review the strongest posts and audience questions before planning the next week.

The calendar is an illustrative campaign concept. It is not a record of posts published for a client. The report and proposal are reusable templates, not completed client deliverables.

## Suggested workflow
**Brief → plan → produce → approve → publish → respond → measure → improve**

For each post, assign an owner, an asset, a call to action and a publication date. Confirm event details and service claims before approval.
